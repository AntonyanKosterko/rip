# Определение времени видимости МКС с Земли

Лабораторная работа №1 — РИП, МГТУ им. Н.Э. Баумана.

**Тема 18:** Определение времени видимости МКС с Земли.

**Услуга** — конкретная точка на Земле с координатами наблюдателя, для которой можно рассчитать время видимости МКС.

**Заявка** — расчёт времени и горизонтальных координат МКС для выбранных наблюдателей на заданную дату.

Стилистика: [roscosmos.ru](https://www.roscosmos.ru)

## Быстрый запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить Minio
docker compose up -d

# 3. Запустить сервер
python manage.py runserver
```

Приложение доступно по адресу: http://localhost:8000

Консоль Minio: http://localhost:9001 (minioadmin / minioadmin)

## Структура

- **Страница 1** — `/` — Список точек наблюдения (услуги) с поиском
- **Страница 2** — `/services/<id>/` — Детальная информация о точке (портретный режим, видео)
- **Страница 3** — `/application/<id>/` — Просмотр состава заявки
