# Определение времени видимости МКС с Земли

Лабораторная работа №1 — РИП, МГТУ им. Н.Э. Баумана.

**Тема 18:** Определение времени видимости МКС с Земли.

**Услуга** — конкретная точка на Земле с координатами наблюдателя, для которой можно рассчитать время видимости МКС.

**Заявка** — расчёт времени и горизонтальных координат МКС для выбранных наблюдателей на заданную дату.

Стилистика: [roscosmos.ru](https://www.roscosmos.ru)

## Лабораторная 1

- **Цель работы:** выбор варианта-темы, знакомство с разработкой бэкенда и разработка дизайна для 3 страниц
- **Стек:** Go (net/http), HTML-шаблоны (html/template), CSS, MinIO
- **Дизайн:** тёмно-синяя тема (#001233, #000B1D), красные квадратные кнопки (#D32F2F), голубой акцент (#019DF8) — стилистика roscosmos.ru

## Быстрый запуск

```bash
# 1. Запустить Minio
docker compose up -d

# 2. Собрать и запустить сервер
go build -o iss-server .
./iss-server
```

Приложение доступно по адресу: http://localhost:8080

Консоль Minio: http://localhost:9001 (minioadmin / minioadmin)

## Страницы

- **Страница 1** — `GET /` — Список точек наблюдения (услуги) с поиском по названию/стране, иконка корзины с количеством
- **Страница 2** — `GET /services/<id>/` — Детальная информация о точке (Vibes-стиль: портретная карточка, видео)
- **Страница 3** — `GET /calculations/<id>/` — Просмотр состава заявки (карточки-таблица)

## Архитектура (MVC)


## Поля

### Услуга (точка наблюдения)
Название, Страна, Координаты (широта, долгота), Высота, Часовой пояс, Лучшее время, Засветка, Погодные условия, Описание, Изображение (MinIO), Видео (MinIO)

### Заявка
Название, Дата наблюдения, Статус, Дата создания, Модератор, Результат расчёта

### М-М (услуга в заявке)
Порядок наблюдения, Основная (да/нет), ФИО наблюдателя, Положение (результат)
